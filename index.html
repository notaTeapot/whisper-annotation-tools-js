Whisper Annotation Converter

Konvertiere Whisper-JSON in .flk oder Sketch Engine XML

Wie die Konvertierung funktioniert

Das Tool nimmt deine Whisper-Daten (und optional Metadaten) und wandelt sie in dein gewünschtes Zielformat um.

1. Input: Whisper JSON

{
  "start": 334.567,
  "end": 338.333,
  "text": "Und es war 18.20 Uhr...",
  "words": [
    { 
      "word": "Und", 
      "start": 334.567, 
      "speaker": "SPEAKER_00" 
    }
  ]
}
➔

Output A: .flk Datei

Kombiniert Metadaten und Transkript in einer Struktur.

{
  "metadata": {
    "title": "Interview 1",
    "date": "2024-05-12"
  },
  "transcript": [ 
    /* Whisper Segmente hier */ 
  ]
}

Output B: Sketch Engine XML

Nutzt <doc> für Metadaten und <u>/<w> für Text.

<doc title="Interview 1" date="2024-05-12">
  <u who="SPEAKER_00" start="334.567" end="338.333">
    <w start="334.567" end="335.128" score="0.782">Und</w>
  </u>
</doc>
