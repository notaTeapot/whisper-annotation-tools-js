Whisper Annotation Converter

Strukturiere Whisper-JSON in Sätze und Paragraphen für FLK oder Sketch Engine

Strukturierungs-Logik (structure.py)

Input (Whisper JSON)

Transkript wird eingelesen und nach Sprechern und Pausen gruppiert.

{
  "metadata": { "name": "Tape 1", "date": "2024-01-01" },
  "speakers": [
    { "text": "Und ", "timestamp": [0.0, 1.0], "speaker": "SPK_0" },
    { "text": "dann.", "timestamp": [1.0, 1.5], "speaker": "SPK_0" }
  ]
}

Output: .flk (Folker XML)

Generiert eine standardkonforme Folker-Datei inkl. Timeline.

<folker-transcription>
  <timeline>
    <timepoint timepoint-id="TLI_1" absolute-time="0" />
  </timeline>
  <contribution speaker-reference="SPK_0">
    <unparsed>Und dann.</unparsed>
  </contribution>
</folker-transcription>
